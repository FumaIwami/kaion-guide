# 会社経営オンライン 攻略ガイド

本文は `content/*.md`（運営だけが書く）。プレイヤーの投稿は Google フォームで受け、
**スプレッドシートで「承認」にチェックしたものだけ**が 1 時間ごとに各ページへ載る。

## 仕組み
```
プレイヤー → Google フォーム → スプレッドシート「フォームの回答 1」(非公開)
                                   ↓ 承認列にチェック(Apps Script が即コピー)
                              公開用シート(承認分だけ・リンク閲覧可) → CSV
                                   ↓ 1 時間ごと
                         GitHub Actions が build.py → GitHub Pages
```
★未承認の投稿は CSV に出ない（公開用シートには承認分しか入らないため）。

## 最初の設定（1 回だけ）
1. https://script.google.com/ → 「新しいプロジェクト」→ 中身を全部消して `tools/setup_form.gs` を貼る → 保存。
2. 上の関数欄で `setup` を選んで「実行」→ 権限の確認（「このアプリは Google で確認されていません」→ 詳細 → 移動 → 許可）。
3. 実行ログに出る JSON（form_url / form_page_entry / approved_csv_url）を `config.json` に入れる。
4. GitHub に公開リポジトリを作って push → Settings → Pages → Source を「GitHub Actions」に。

作られるもの: 投稿フォーム / 回答シート（非公開・E 列「承認」）/ 公開用シート（承認分だけ自動コピー・リンク閲覧可）。
★未承認の投稿は公開用シートに一切入らない。

## 普段の運用
- 投稿の承認: 回答シートで E 列にチェック（スマホ可）。サイトへは最大 1 時間で反映。取り下げはチェックを外す。
- 本文の更新: `content/*.md` を直して push（すぐ反映）。良い投稿は本文に取り込んでから承認を外してもよい。
- 手元で確認: `python3 build.py` → `public/index.html` をブラウザで開く。

## 書式（content/*.md）
先頭に `title` / `order`(並び順) / `status`(「情報募集中」等・任意)。本文は `##` 見出し・`-` 箇条書き・`1.` 番号・表(`|`)・`**太字**`・`> 注記`・`[文字](page.html)`。
